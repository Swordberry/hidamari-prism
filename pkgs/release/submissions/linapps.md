## Description

Hidamari Prism is a video, stream, webpage, and static-image wallpaper engine
for Linux, written in Python as a friendly fork of Hidamari. Hardware decoding
by default with automatic CPU fallback, playlists with in-order or shuffle
playback, pause-and-mute when a window is maximized, and multi-monitor support.
